# 🚬 Marlboro Project — Telegram RPG Bot

Масштабный Telegram RPG / RP / Economy бот с полной игровой экономикой.

## 🎮 Возможности

- 👤 Профиль, уровни, XP система
- 💰 Экономика, банк, переводы
- 🏪 Магазин с категориями
- 📦 Кейсы / лутбоксы (5 видов)
- ⚔️ PvP / Дуэли со ставками
- 🎰 Казино: слоты, рулетка, кости, блэкджек, монетка
- 💼 Работа (8 профессий)
- 🌾 Ферма (посев, сбор урожая)
- ⛏️ Майнинг (6 видов ресурсов)
- 🏭 Бизнесы (6 видов, пассивный доход)
- 🏴 Кланы (создание, управление, казна)
- 🏛️ Аукцион (торги в реальном времени)
- 🔁 Обмен предметами между игроками
- 💍 Браки и друзья
- 🎭 RP команды
- 🌟 RPG события
- 🎁 Ежедневные бонусы со стриком
- 👥 Реферальная программа
- 🎟️ Промокоды
- 💫 VIP система (Silver / Gold / Platinum)
- 🏅 50+ достижений
- 🚫 Система банов и мутов
- 📊 Топ игроков (4 категории)
- 🛠️ Полная админ панель

## 🚀 Установка

```bash
cd marlboro-bot
pip install -r requirements.txt
cp .env.example .env
# Заполни .env токеном и настройками
python main.py
```

## ⚙️ Конфигурация (.env)

```
BOT_TOKEN=ваш_токен
OWNER_ID=5341321001
LOG_GROUP_ID=-100xxxxxxxxx  # ID группы для логов
```

## 🛠️ Команды администратора

| Команда | Описание |
|---------|----------|
| `/admin` | Панель администратора |
| `/give` | Выдать монеты |
| `/giveitem` | Выдать предмет |
| `/givevip` | Выдать VIP |
| `/ban` | Забанить игрока |
| `/unban <id>` | Разбанить |
| `/mute` | Замьютить |
| `/createpromo` | Создать промокод |
| `/logs` | Последние логи |
| `/exportdb` | Экспорт базы данных |
| `/backup` | Создать backup |
| `/restart` | Перезагрузить бота |

## 📁 Структура

```
marlboro-bot/
├── main.py              # Точка входа
├── config.py            # Конфигурация
├── requirements.txt
├── .env                 # Токены (не коммитить!)
├── database/
│   ├── db.py            # БД и все таблицы
│   └── backup.py        # Backup утилиты
├── handlers/            # Обработчики команд
├── middlewares/         # Anti-spam, ban, register
├── utils/               # Утилиты, клавиатуры, тексты
└── data/
    ├── items.json        # 50 предметов
    └── cases.json        # 5 кейсов
```
